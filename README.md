# NISHCHAY Prototype

Prototype for SIH26036 - Digital verification and certification platform for Legal Metrology.

## Quickstart

1. Install Node.js 22 or 24 LTS
2. Run `npm ci`
3. Run `npm run verify` to ensure tests and types are passing
4. Run `npm run start` (or `npm run dev` for development)
5. Access the app at http://localhost:4000
