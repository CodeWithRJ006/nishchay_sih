# NISHCHAY Prototype - Design System

**Tokens**:
- Backgrounds: Gauge Steel (#EEF2F5) for canvas, White for cards.
- Text: Ink (#0D1B26) for primary, dark gray for secondary.
- Primary Action: Calibration Blue (#0F4C81).
- Status Fills: Verified Green (#0B7A5A), Stamp Amber (#B7791F), Seal-Break Red (#B3261E). Amber text uses #8A5A00 for AA contrast.

**Type Scale**:
- Fonts: Bricolage Grotesque (headings), Source Sans 3 (UI), JetBrains Mono (IDs).
- Scale: Headings from 24px (h3) to 36px (h1). UI text 16px base, 14px secondary.

**Shells**:
- Desktop: Left rail navigation mapped to role permissions. Top bar for current role identity, sign out, and Demo badge.
- Mobile Field: Bottom action bar, ruthless focus on one task per screen. No heavy sidebars.

**Motif**: Measurement-scale tick marks used for progress timelines instead of generic dots or steppers.

**Rejected Generic Elements**:
- Removed identical-card grids, heavy gradient washes, all-caps eyebrows, and exclamation marks.
- Avoided map tile services in favor of an inline SVG distance diagram.
